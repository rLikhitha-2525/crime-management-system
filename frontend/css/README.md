# CSS Documentation

Main stylesheet: `frontend/css/styles.css`

## What it styles

- global page theme (dark background, white text)
- navbar brand emphasis
- stat cards and form cards
- map container sizing and radius
- reusable toast style
- admin table wrapper panel
- responsive map height adjustments

## Design intent

- keep a consistent dark dashboard look across all pages
- centralize styling so HTML files stay mostly structure-only
- make future page additions reuse the same utility classes

## Key reusable classes

- `.stat-card`
- `.form-card`
- `.alert-toast`
- `.table-wrapper`
